# FixAR: «Мой день» — интерактивный прототип

Адрес: `/v2/day/`. Самостоятельная статическая страница, сборка не требуется.
Рабочая оболочка `/v2/` остаётся отдельной.

## Что можно пройти

1. Главная: крупный чат, быстрые вопросы, важное на день, карточки помощников.
2. Дело Домашкина: список предметов, раскрытие разбора, ручное сворачивание результата.
3. Сохранение в материалы и скачивание настоящего TXT-файла с демонстрационным разбором.
4. Добавление демо-участника с ролью, назначение помощника и срока.
5. Пример выбора Telegram / MAX для ежедневной сводки, подтверждение завершения.
6. Переключение между семейным, личным пространством и практикой с другим основным агентом.
7. «Попробовать»: три сценария; «Дизайн-система»: повторно используемые компоненты.
8. Постоянно видимый слайдер «Цвет настроения» и явный переключатель RU / EN;
   английский применяется ко всем плиткам, формам и динамическим состояниям.
9. Отдельный переключатель «Светлая / Тёмная»; выбор сохраняется после
   перезагрузки и применяется ко всем карточкам, формам и диалогам.

Все данные вымышлены. Нет вызовов API, ИИ, дневника, отправки приглашений,
уведомлений или списаний. Не вводить реальные персональные данные.
Прогресс хранится только в `fixar.day.prototype.v1` в localStorage. Сброс очищает
только состояние демо. RU/EN переключает прототип, не меняя язык рабочего сайта.
Текст запроса отображается рядом с заранее подготовленным примером; это не ответ ИИ.

## Основа для масштабирования

`day.css` содержит общие семантические токены: `--ink`, `--muted`, `--paper`,
`--surface`, `--line`, `--accent`, `--soft`, `--radius`, `--shadow`.
Акцент определяется `--hue`; содержимое и расположение карточек от него не зависят.
Используются системные шрифты, локальные SVG-иконки; внешних зависимостей и CDN нет.

`day.js` разделяет данные (`spaces`, `agents`), состояние и функции компонентов.
RU/EN задаются явно в данных и шаблонах, пользовательский текст не переводится.

| Компонент | Функция / селектор | Данные при переносе |
| --- | --- | --- |
| Главное на день | `.hero`, `data-component=day-highlight` | Одно подтверждённое событие, источник, действие |
| Карточка помощника | `agentCard`, `data-component=assistant-card` | Agent ID, Case ID, разрешённая сводка, серверный статус |
| Следующее действие | `nextStep`, `data-component=next-step` | Доступность по правам, тип действия, состояние выполнения |
| Диалог | `composer`, `.composer` | Черновик, отправка, ожидание, ошибка; отдельно результат |
| Результат | `caseScreen`, `data-component=result` | Материалы дела, источники, состояние раскрытия |
| Первые шаги | `onboarding`, `data-component=onboarding` | Завершённые полезные действия и возможность скрыть |
| Сценарий знакомства | `.scenario` | Ожидаемый результат, цена, материалы и разрешения до запуска |
| Диалоговое окно | `openModal`, нативный `dialog` | Заголовок, содержимое, подтверждение и отмена |

При переносе сначала подключить один настоящий семейный сценарий к этим
компонентам. Заменить локальные изменения в `updateCase` на серверные операции;
отображать завершение только после успешного ответа. Для списков и материалов
предусмотреть загрузку, пустой результат, отказ в доступе и повтор ошибки.
Для приглашений, ролей, данных детей и уведомлений сохранить серверную проверку
прав. Состояние `working` из витрины не означает действующий фоновый процесс.
Стоимость примера «0 кредитов» не переносить на реальные операции.

## Проверка и preview

Из корня aiOS2 запустить статику:

```bash
python3 -m http.server 8877 --directory infrastructure/agrigate-pro/site
```

В окружении с Playwright и Chromium:

```bash
python tests/fixar_day_browser.py --url http://127.0.0.1:8877/v2/day/
```

Можно задать `--browser /path/to/chrome` и `--output /tmp/fixar-day-preview`.
Smoke проходит сценарий на ширинах 1440, 390 и 320, сохраняет PNG светлой и
тёмной главной, дела, витрины компонентов и JSON-отчёт. Проверяет клавиатурный фокус модалки,
Escape/overlay, рост поля, сворачивание ответа, формы, сохранение, скачивание,
смену кабинета, язык, палитру, сохранение темы после перезагрузки и сброса,
а также отсутствие вызовов API.
