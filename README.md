# ФиксАР — фронтенд

Статическая оболочка ФиксАР (frontend), которую видит пользователь на
**https://agrigate.pro**. Только клиентский код: HTML, CSS, ванильный JS — без
сборки и без секретов.

## Что внутри

| Путь | Назначение |
|------|-----------|
| `index.html`, `start.js` | точка входа оболочки, загрузка сессии |
| `owner-console.js/.css` | закрытый кабинет владельца (доступен только владельцу) |
| `lang.js`, `lang-en.js` | локализация RU/EN |
| `document-canvas.*`, `document-export.js` | экран документа и экспорт |
| `auth/` | коллбэки входа (VK, Telegram, MAX, callback) |
| `vhod/`, `svod/`, `spravka/`, `podbor/`, `pak/`, `dnevnik/`, … | страницы оболочки |
| `space/` | прототип пространственной оболочки |
| `vendor/` | сторонние библиотеки (напр. jsPDF) |

## Бэкенд

Фронтенд обращается к публичному шлюзу aiOS2: **https://api.agrigate.pro**
(`start.js` → `var API`). Здесь только клиент — серверная часть в основном
репозитории платформы.

## Выкладка

Продакшн отдаётся с **Bunny CDN** (pull-zone перед `agrigate-pro.b-cdn.net`).
Это зеркало-снимок фронтенда; источник истины — монорепозиторий aiOS2.
